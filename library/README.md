# Biblioteca visual

O catálogo começa vazio. As imagens serão criadas pelo gerador integrado do Codex ou fornecidas pelo usuário em produções reais. Somente materiais inspecionados e explicitamente aprovados entram em `assets/`; candidatos permanecem no projeto de origem.

Cada item tem identificador, versão, bytes próprios, hash, descrição observada, origem e aprovação. Cada vídeo importa uma cópia independente. Não há modelos, pesos, embeddings ou geração local.

Veja [criação de imagens](../workflow/imagens-codex.md) e [biblioteca](../workflow/biblioteca.md).
